# Flutter Vocabulary App 📚

Мобільний додаток на Flutter для вивчення англійських слів з перекладами.

## Особливості

- ✏️ **Екран введення слів**: Додавайте пари слово-переклад у зручному списку
- 📊 **Таблиця слів**: Перегляд всіх доданих слів у вигляді таблиці
- 🎨 **Сучасний UI**: Material Design 3 з красивим інтерфейсом
- 📱 **Адаптивний дизайн**: Працює на Android та iOS

## Структура проекту

```
lib/
├── main.dart                          # Головний файл додатку
├── models/
│   └── word_pair.dart                 # Модель даних для пари слово-переклад
└── screens/
    ├── word_input_screen.dart         # Екран введення слів
    └── words_table_screen.dart        # Екран з таблицею слів
```

## Як використовувати

### Екран введення слів
1. Вводьте англійські слова та їх переклади у відповідні поля
2. При введенні автоматично з'являється нова пара полів
3. Натисніть кнопку **Next** вгорі, щоб перейти до таблиці

### Екран таблиці
- Переглядайте всі додані слова у зручному табличному форматі
- Таблиця показує номер, слово та переклад

## Встановлення та запуск

### Вимоги
- Flutter SDK (3.0.0 або новіше)
- Dart SDK
- Android Studio / Xcode (для запуску на емуляторах)

### Кроки встановлення

1. **Клонуйте або перейдіть до папки проекту**:
   ```bash
   cd /Users/max/CascadeProjects/flutter_vocabulary_app
   ```

2. **Встановіть залежності**:
   ```bash
   flutter pub get
   ```

3. **Запустіть додаток**:
   ```bash
   flutter run
   ```

### Запуск на конкретній платформі

```bash
# Android
flutter run -d android

# iOS (тільки на macOS)
flutter run -d ios

# Chrome (веб-версія)
flutter run -d chrome
```
