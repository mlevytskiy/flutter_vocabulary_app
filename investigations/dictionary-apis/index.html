Descriptions

Free Dictionary API (dictionaryapi.dev)

no registration · docs

Volunteer-run, keyless JSON API built on Wiktionary data, with phonetics and sometimes UK/US audio links.

Audio files are named *_gb_* / *_us_* and exist only for some words. Returned HTTP 522 on all ten words across two attempts on 2026-09-24 (host timing out).

Merriam-Webster Dictionary API

self-serve · docs

Merriam-Webster's Collegiate/Learner's dictionaries as JSON, with American pronunciation audio.

Oxford Dictionaries API

self-serve · docs

Oxford Languages' dictionary data with multiple senses and British-led pronunciation audio.

Plans: Lite / Growing / Enterprise. Lite and Growing prices are behind a login; only Enterprise is public at ≈ £5,000/yr per language. AmE audio is limited. The sandbox's A-words-only limit means most of the ten fixture words cannot be tested without a paid plan.

Cambridge Dictionary API

manual approval · docs

Cambridge's learner and general dictionaries with both British and American audio, commercial access only.

Commercial pricing is undisclosed.

Collins Dictionary API

manual approval · docs

Collins English dictionary data with multiple senses and British-led pronunciation audio.

AmE audio is unclear from public docs; task-16 settles it empirically if a key is obtained.

WordsAPI (RapidAPI)

self-serve · docs

Definitions grouped by part of speech plus word relations (synonyms, etc.), with IPA text but no audio.

Pronunciation is IPA text only.

API Ninjas Dictionary

self-serve · docs

Minimal single-definition lookup, part of a large generic API bundle.

One definition string with the senses numbered inline (Webster 1913-style); the adapter splits it. No audio. Returned nothing for inflected forms (flustered, circumstances) on 2026-09-27.

Datamuse

no registration · docs

Fast word-finding API that can attach short definitions (md=d) and Arpabet pronunciation.

1–few senses. Pronunciation is Arpabet text, no audio. A key becomes required from 2027 (self-serve). Returned 200 in ~0.33 s on 2026-09-24.

Wiktionary REST API

no registration · docs

Wikimedia's REST endpoint returning Wiktionary definitions by part of speech, as HTML fragments.

Audio only sometimes. Definitions are HTML-wrapped. Returned 200 in ~1.9 s on 2026-09-24, but 404 on the idiom.

Wiktextract / kaikki.org

no registration · docs

Machine-readable dump of all of Wiktionary, with senses and Wikimedia Commons audio for UK and US.

Not a live API — bulk download only, so the harness cannot probe it.
