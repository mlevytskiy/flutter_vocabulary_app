# Changelog — get-words-from-subtitles-improvment

## get-words-from-subtitles-improvment — film dialogues with their words in bold, on the phone, the shared page and the learn page

**What:** A new Settings switch, "Get dialogues from subtitles", is off by default. When it is on, a subtitle import also keeps up to 10 film dialogues, each with up to 8 lines and each holding some of the proposed words. After Done, the main screen becomes a pager. Its first page is the main screen as before, and each further page is one dialogue, with its words in bold and listed under it with translation and definition. The shared page shows the same dialogue pages after the word table. A later import's rows and dialogues, and scene pictures, reach an existing shared link on their own. On the learn page, a new Step 1 exercise, "Dialogs from movie", uses one word group per dialogue plus "Other words". Its Start shows the dialogue and draws a scene picture as a two-step story run, which takes one unit from the daily story allowance. With the switch off, or in a session without dialogues, the app works as before. The only difference is one greyed exercise on the learn page.

**Why:** Learners who import a film want its best moments kept next to the words, and want to learn the words in the scenes they came from ([spec](spec.md) §1, §2). The AI picks words and dialogues in the same request, so dialogues never add words and the word maximum still applies ([ADR-0002](adr/0002-pick-words-and-dialogues-in-one-ai-request.md)). Every bold word is checked against its dialogue with one matching rule, shared by the Worker and the app (AC-05). Dialogues live in the session and link to their words by row id, so edits and deletes only ever shrink them ([ADR-0003](adr/0003-keep-film-dialogues-in-the-session-and-link-their-words-by-row-id.md)). Scene pictures reuse the story run workflow as two-step runs ([ADR-0004](adr/0004-draw-scene-pictures-as-two-step-runs-of-the-story-run-workflow.md)). Imports are appended to a published session automatically ([ADR-0005](adr/0005-add-an-imports-rows-and-dialogues-to-the-published-session-automatically.md)). The change spans three surfaces: app, Worker and shared page ([ADR-0001](adr/0001-change-the-app-the-worker-and-the-shared-page-as-three-surfaces.md)).

**How to use:** Main screen → Settings → turn on "Get dialogues from subtitles" → speed dial → subtitle import → Done. Swipe left on the main screen to see the dialogues. Words → Learn → tick "Dialogs from movie" → pick a dialogue group → Start. Share works as before; the partner swipes from the table to the dialogue pages.
Worker: `POST /subtitles/words` accepts `"dialogues": true` and returns `dialogues: [{lines, words}]` next to `words`. `POST /sessions` accepts `dialogues`. New: `POST /sessions/{id}/dialogues` (append an import; needs the app secret and `x-edit-token`; idempotent per `importId`), `POST /sessions/{id}/dialogues/{dialogueId}/picture` (upload a scene picture; same auth), and the public `GET /s/{id}/dialogues/{dialogueId}/picture`. `POST /story/runs` accepts `kind: "scene"`.

**Operational notes:**
- Migration: adds D1 migration `0005_film_dialogues.sql`, with the rollback in `migrations/down/0005_film_dialogues.sql`. The branch also carries `0004_story_runs.sql` from mnemonic-story, which master does not have yet. Before deploying, run `wrangler d1 migrations apply DB --remote` (0004 first, then 0005).
- Feature flag / config: the app switch "Get dialogues from subtitles" is off by default. No new Worker secrets: scene pictures use the picture keys mnemonic-story already uses.
- Rollback: revert the Worker deploy, then run `npx wrangler d1 execute DB --remote --file migrations/down/0005_film_dialogues.sql` from `vocab-photo-api/`. Sessions published while the feature was live lose their dialogues on the shared page, but their rows are kept. App builds without the feature ignore `dialogues` in replies.

**Acceptance criteria delivered:** AC-01 – AC-26. Dialogues are opt-in, picked with the words and checked so every bold word appears (AC-01–AC-09). They follow edits, imports and session switches (AC-10–AC-12, AC-21, AC-23, AC-26). "Dialogs from movie" groups, scene pictures and the shared allowance cover AC-13–AC-19 and AC-24–AC-25. Shared-page dialogues and automatic append cover AC-20. The web stays read-only for AI work (AC-22).
