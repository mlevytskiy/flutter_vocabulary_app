## Glossary

- explanation — the English text the learner types for a word in Type mode, checked once for meaning only; it must not hold the word in any form, a translation or Ukrainian. NOT an own sentence (which must use the word) and NOT a definition from the dictionary.
- mode — Type or With a friend, chosen once per open before the first word and kept for every round. NOT the kit's practice / exam field mode.
- friend — the person next to the learner in With a friend mode who hears the spoken explanation and taps Understood or Not yet on the same phone. NOT a partner (a viewer of the shared page) and NOT anyone on the web.
- countdown — the time a card allows (90 s Type, 30 s With a friend), shown as m:ss, starting when the card shows, never paused. NOT a score: time taken is not recorded.
- time up — a Type word whose countdown reached zero with nothing sendable typed; it ends as repeat with no check.
