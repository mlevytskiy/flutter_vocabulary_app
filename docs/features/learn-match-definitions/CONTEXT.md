## Glossary

- definition line — the one line of a word's definition that a card shows: the text after "definition:" when the stored definition has such a line (a picked dictionary sense), else its first line that is not an example. NOT the whole stored definition (its example line is never shown on a card).
- round definition — a definition the Worker gives for one word, in the sense of its translation, because the word has no stored definition line; it lives only while the exercise is open. NOT the word's definition (it is never written to the word).
- usable word — here: a word to learn of the selected group that has a definition line (stored or round definition) whose card text still says something after masking and does not read the same as another card of the board. NOT the usable word of match-synonyms (that one needs a synonym).
