# Domain Context — definition-mode

## Glossary

- definition — a short English explanation of a word's meaning, either written for the word's context in the photo or picked from the dictionary's senses. NOT translation (a translation gives the Ukrainian equivalent, not an explanation).
- senses — the dictionary's short meanings for one word, from which the learner can pick a definition. NOT translation alternatives (those are other Ukrainian equivalents, not English explanations).
- word detail mode — the learner's choice in Settings between translation, definition, or both, applied to every word row. NOT drag-and-drop mode (that only controls reordering rows).

## Invariants

- Changing the word detail mode never deletes a stored translation or definition; it only changes what is shown.
