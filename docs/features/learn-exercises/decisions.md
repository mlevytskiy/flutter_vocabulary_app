# Shared decisions — learning exercises

Decisions that affect more than one exercise. Every improvement pass reads this file first and
appends what it decided. Agent decisions are marked **(agent, date)**; the owner may revise any.
Format: `D-NN — question → decision. Why. Affects: ids.`

## Open (cross-cutting)
- Saving the Step 3 result (known / repeat per word) needs an owner-approved record or WordPair field (rule 5). Until then it is show-only (D-33).
- `docs/lightning_icon_rules.md` covers only the AI-translate buttons; it does not map results to
  known / repeat. Step 3 results do not touch the lightning icons until the owner says so.

## Decided

D-01 — Which board widget do the match exercises share? → One "match board": two columns, tap-then-tap, right pair locks, wrong pair shakes and unselects, per-word miss count, summary at the end. match-synonyms builds it; antonyms and definitions reuse it with different pair data. Why: same interaction, avoids three copies. Affects: match-synonyms, match-antonyms, match-definitions. (agent, 2026-10-14)
D-02 — How many words per round in match exercises? → 3 to 6 pairs; larger groups split into rounds, never a round under 3; fewer than 3 usable words shows a "not enough words" screen. Why: fits one phone screen and keeps the round meaningful. Affects: match-synonyms, match-antonyms, match-definitions. (agent, 2026-10-14)
D-03 — Where is AI exercise data (synonyms, antonyms, definitions, clues) generated and cached? → On the Worker: one call per group, cached per word there. The app keeps nothing new on disk and adds no field to WordPair (CLAUDE.md rule 5). Why: no new model; repeat opens are free. Affects: match-synonyms, match-antonyms, match-definitions, guess-my-word, fill-the-gaps. (agent, 2026-10-14)
D-04 — What does a Stage 1 exercise record? → Per-word misses for the round, shown in the end summary only; nothing saved. Step 3 owns saved results. Why: matches the open Step 3 decision. Affects: all Stage 1 and 2 exercises. (agent, 2026-10-14)
D-05 — What happens when exercise data cannot load? → An error line with Retry; no partial round. Why: one predictable behaviour. Affects: all exercises using AI data. (agent, 2026-10-14)
D-06 — Which sense does the AI use for a word? → The Worker gets the word and its translation and answers for that sense; it may return "none" for a word. Why: "light" or "bank" would otherwise give wrong answers. Affects: match-synonyms, match-antonyms, match-definitions, guess-my-word, fill-the-gaps. (agent, 2026-10-14)
D-07 — Can an answer equal another word of the same match round? → No. The AI is told to avoid it; if it happens anyway, only the first word in group order stays in the round and the other is left out of it. Why: two valid answers make a fair miss impossible. Affects: match-synonyms, match-antonyms, match-definitions. (agent, 2026-10-14)
D-08 — Does an exercise that shows a definition or clue reveal its own word? → No. The word, as a whole word in any case, shows as "___" inside any definition, clue or example sentence on a card. Why: otherwise the answer is given away. Affects: match-definitions, guess-my-word, fill-the-gaps. (agent, 2026-10-14)
D-09 — Where does an exercise take a word's definition from? → The row's stored `definition` first (the learner's chosen sense). If empty, the Worker `/define` (dictionary, first sense), used for the round only and never written to the word. A translation is never a stand-in. Why: keeps the chosen sense, adds no field. Affects: match-definitions, guess-my-word, fill-the-gaps. (agent, 2026-10-14)
D-10 — How long may text on a match card be? → About 120 characters; longer text is cut at its first sentence, else at a whole word plus "…". Why: cards must fit a phone column. Affects: match-synonyms, match-antonyms, match-definitions. (agent, 2026-10-14)
D-11 — Is any "People" feature on the shared page (buzzer, votes, turns, people-written text) in v1? → No. The shared page is a published snapshot with no live state or write-back. All exercises are app-only in v1; People sections describe later steps and need their own spec first. Why: no live multi-user state exists today. Affects: guess-my-word, chain-story, explain-to-friend, match-synonyms. (agent, 2026-10-14)
D-12 — How is a round scored when it has a score per word? → Score per word is kept on screen in the end summary only (0 = not found). Wrong guesses after the last clue end that word with 0 and show the answer; no endless guessing. Why: ends every round and fits D-04. Affects: guess-my-word, pick-the-answer, quiz. (agent, 2026-10-14)
D-13 — How big is a round for grid-style exercises? → 3 to 9 words when the learner picks from a grid (same even-split rule as D-02, no round under 3). Why: a grid wraps on a phone; match boards stay 3 to 6. Affects: guess-my-word, pick-the-answer. (agent, 2026-10-14)
D-14 — What is the shared question builder contract (pick-the-answer, quiz)? → A pure function `buildQuestion(word, pool, kind, random)`: no I/O, no state. Kind A = word → 4 translations; kind B = meaning → 4 English words. Returns prompt text, 4 distinct options, right index, word id; or null if 4 distinct options cannot be made. Same input and seed give the same question. Why: Quiz and pick-the-answer must not fork. Affects: pick-the-answer, quiz. (agent, 2026-10-14)
D-15 — Where do wrong options (distractors) come from, and what may they not be? → Other words of the group first, then the learner's other words; never AI. Never equal (ignoring case and spaces) to the right option or to each other; words with no translation are not used. Why: no AI cost and no two right answers. Affects: pick-the-answer, quiz, fill-the-gaps (if it offers options). (agent, 2026-10-14)
D-16 — What is the "meaning" when a prompt needs one but no AI is wanted? → The row's stored definition, else its translation; no /define call. D-08 masking still applies. Why: keeps offline exercises offline; refines D-09 for exercises where a definition is optional. Affects: pick-the-answer, quiz. (agent, 2026-10-14)
D-17 — Is a choice answer final? → Yes: the first tap is the answer, shown right or wrong at once, no retry. Why: keeps "first try" scoring clear. Affects: pick-the-answer, quiz. (agent, 2026-10-14)
D-18 — How is a typed answer matched (fill-the-gaps and any later typed exercise)? → Compare after trimming, lowercasing, collapsing inner spaces and dropping a leading "to " or article (a/an/the) on both sides. Exact match = right. One-letter slip (one add, drop, change or swap of neighbours) on words of 5+ letters = "almost", counted as right and the correct spelling shown; shorter words need an exact match. Other word forms (-ed, -s, -ing) are wrong. Why: tests the stored word, forgives phone typos, no AI call. Affects: fill-the-gaps, own-sentences, translate-sentences, quiz. (agent, 2026-10-14)
D-19 — How does a typed question behave on a phone? → Keyboard opens at once, autocorrect and suggestions off, Send key submits, a miss shows first letter and letter count, one retry, then the answer. A "Show answer" button ends the word as missed. Why: autocorrect would change the answer. Affects: fill-the-gaps, quiz. (agent, 2026-10-14)
D-20 — Where does an exercise sentence come from? → A line of a dialogue linked to the word (`FilmDialogue.wordRowIds`) that contains the word as a whole word, else one Worker sentence per group (D-03, D-06); it must hold the word exactly once (D-08 masking). Why: dialogue lines are free and in context. Affects: fill-the-gaps, quiz, sentence-patterns, translate-sentences. (agent, 2026-10-14)
D-21 — How does a self-rated exercise (flashcards) fit the stages? → Stage 2 if the learner must recall the word before seeing it; its rating is a summary hint only and is never a Step 3 result unless the owner says so. Why: self-report is not proof. Affects: remember-or-not, own-sentences, explain-to-friend, quiz. (agent, 2026-10-14)
D-22 — When does an exercise play TTS? → On tap of a speaker button only, in the learner's accent, never automatically; the exercise shows the speaker only after the word is revealed. Why: no spoilers, quiet places stay quiet. Affects: remember-or-not, fill-the-gaps, pick-the-answer, quiz. (agent, 2026-10-14)
D-23 — Do exercises use swipe gestures? → No in v1: explicit buttons only. Why: testable and visible. Affects: remember-or-not, all exercises. (agent, 2026-10-14)
D-24 — What is the AI sentence-check contract (sentence-patterns, own-sentences, translate-sentences, chain-story)? → One Worker call per learner sentence, never batched, not cached. Input: `{word, translation, sentence, task, extra}`; `task` is "pattern" (extra = the pattern), "own" (extra empty), "translate" (extra = the source sentence) or "story" (extra = the story so far). Output: `{usesWord: bool, usesTask: bool, ok: bool, fixed: string, note: string}`. `ok` is true only if `usesWord`, `usesTask` and the sentence has no grammar or spelling error; then `fixed` is empty. Otherwise `fixed` is one corrected sentence that keeps the learner's meaning and `note` is one line of at most 100 characters in plain English. The word counts in any inflected form. The app only pre-checks: not empty, at least 2 words, at most 200 characters. Why: one shared shape lets four exercises share one endpoint and one result widget. Affects: sentence-patterns, own-sentences, translate-sentences, chain-story, own-sentences-spoken, translate-sentences-spoken. (agent, 2026-10-14)
D-25 — What if a sentence check fails, times out (15 s) or the phone is offline? → D-05 applies: error line with Retry, the typed sentence stays, no partial result. A word never checked is "skipped" (0). Why: never score a sentence that was not checked. Affects: sentence-patterns, own-sentences, translate-sentences, chain-story. (agent, 2026-10-14)
D-26 — How does the app map a check to a word result? → right = `ok`; fixed = not `ok`; skipped = no check or the learner tapped Skip. The learner may send once per word. Why: keeps the result vocabulary the same across exercises. Affects: sentence-patterns, own-sentences, translate-sentences. (agent, 2026-10-14)
D-27 — How is generated text shown with the word emphasised? → The AI returns plain text only (no markdown); the app bolds the whole-word match itself. Why: no stray markup from the AI; one tested bolding function. Affects: sentence-patterns, own-sentences, translate-sentences. (agent, 2026-10-14)
D-28 — Does the app have speech-to-text for exercises? → No. The app has no speech-recognition package and rule 5 forbids new ones without the owner. Every exercise takes typed input in v1; "say it" / "dictate" parts are cut until the owner approves a package. TTS (speaking out) is unaffected. Why: no new packages. Affects: chain-story, own-sentences-spoken, translate-sentences-spoken, explain-to-friend, any spoken exercise. (agent, 2026-10-14)
D-29 — Do exercises save a finished product of the learner (a chain, an explanation, "our version")? → No in v1: no new record or StoryRun kind (rule 5, D-04). Any "save" idea waits for an owner-approved record. Why: same as the open Step 3 record. Affects: chain-story, explain-to-friend, own-sentences. (agent, 2026-10-14)
D-30 — Which language does an exercise show when it builds on the Mnemonic story? → The story as built (Ukrainian sentences with English words, split at "→"); the exercise never translates it. The learner writes English. Why: no extra AI cost, keeps the built story. Affects: chain-story, any later story-based exercise. (agent, 2026-10-14)
D-31 — What is the Step 3 result scale? → Two labels per word: known, repeat. A third state "not checked" means no result (no label). No numeric score is shown or kept (replaces the 0-3 idea). Why: matches the owner's "known well / needs repeating". Affects: own-sentences, own-sentences-spoken, translate-sentences, translate-sentences-spoken, explain-to-friend, quiz. (agent, 2026-10-14)
D-32 — How does an exam exercise map to the scale? → Sentence checks: right = known; fixed = repeat; skipped (learner tapped Skip) = repeat. Answer exercises (quiz): right on the first try = known; wrong, "almost" kept as right per D-18, shown answer or skipped = repeat. A word never examined (error, left early) = no result. Self-rated exercises give no result (D-21). Why: one rule, no half marks. Affects: all Stage 3 exercises. (agent, 2026-10-14)
D-33 — Where is the Step 3 result stored? → Nowhere in v1: it is shown in the round summary only (extends D-04). Saving needs a new record or a WordPair field, so it waits for the owner (rule 5). Why: least invasive; the exercise still works. Affects: all Stage 3 exercises. (agent, 2026-10-14)
D-34 — What makes a Stage 3 exercise an exam? → The screen shows only the prompt the spec names: no hint, translation, pattern, example or speaker unless the spec lists it; one checked answer per word; no edit after check and no retry of the word; Skip allowed and counts as repeat. A retry after a network error resends the same answer and is not a second try (refines D-17, D-19, D-25). Why: results must be comparable. Affects: all Stage 3 exercises. (agent, 2026-10-14)
D-35 — How do spoken variants relate to typed ones? → A spoken variant is a "Speak" mode of its typed exercise (own-sentences, translate-sentences), not a separate exercise, with the same round, check, result and exam rules; only the input differs. Blocked until the owner approves a speech-to-text option (D-28). Why: one result vocabulary and one test set. Affects: own-sentences-spoken, translate-sentences-spoken. (agent, 2026-10-14)
D-36 — How does speech input work in an exam once speech-to-text exists? → Mic tap to start and stop (auto-stop after 3 s of silence, at most 20 s); the transcript is read-only; one re-record before the check, none after; the app only capitalises and adds a full stop; denied mic offers the written mode; an empty or one-word transcript is not sent. Why: fair to recognition errors while D-34 still holds. Affects: own-sentences-spoken, translate-sentences-spoken, explain-to-friend, chain-story. (agent, 2026-10-14)
D-37 — What language and direction do translation exercises use? → Learner's language (the language of the stored translations) to English, fixed; no setting. Why: the app serves Ukrainian learners and the stored translation is the cue. Affects: translate-sentences, translate-sentences-spoken. (agent, 2026-10-14)
D-38 — Where does the prompt sentence of a translation exercise come from, and how does it avoid giving the word away? → One Worker call per group returns a Ukrainian sentence plus a model English translation that holds the word once; the Ukrainian sentence must not contain the English word (app drops it if so, D-08), and its translation part is bold as the cue. The model translation shows only after the result. Dialogue lines are English and not used here (narrows D-20). Why: no spoiler, one call per group. Affects: translate-sentences, translate-sentences-spoken. (agent, 2026-10-14)
D-39 — Does a correct sentence that avoids the target word count? → No in word exams (translate): `usesWord` must be true, so a synonym gives `ok` false, result repeat, note names the word. Why: the exam measures this word; the bold cue makes it fair. Affects: translate-sentences, own-sentences, translate-sentences-spoken. (agent, 2026-10-14)
D-40 — How do timers and the "explain" check work in exams? → A countdown exists only where the spec names it, starts when the word shows, and at zero sends the text typed so far (empty text = repeat, no check); it is never paused. D-24 gets a task "explain" (extra empty): `ok` is true only if the text explains the meaning of the word in English, contains no Ukrainian or translation, and does not contain the word in any form; `usesWord` here means "contains the word" and must be false; grammar and spelling are not judged and `fixed` stays empty. Why: a typed timer must not lose the answer; explaining tests meaning, not grammar. Affects: explain-to-friend, any timed exam. (agent, 2026-10-14)
D-41 — How does a typed question behave inside an exam (Quiz, any later exam with a typed gap)? → D-34 wins over D-19: no first-letter hint, no retry, no "Show answer"; Skip counts as repeat. Matching stays D-18 ("almost" counts as right). Why: results must be comparable. Affects: quiz, any Stage 3 typed gap. (agent, 2026-10-14)
D-42 — Who chooses the question kind of the shared builder? → The caller: pick-the-answer alternates A/B, the Quiz uses its own rule. This closes the owner question in pick-the-answer. Why: the builder is pure (D-14). Affects: pick-the-answer, quiz. (agent, 2026-10-14)
D-43 — In an exam, when is right or wrong shown for choice questions? → Only in the summary (D-34 overrides D-17's instant colour); the first tap is still final. Why: no feedback leaks between questions. Affects: quiz, any Stage 3 choice question. (agent, 2026-10-14)

## Conflicts noticed
- D-09 "a translation is never a stand-in for a definition" vs D-16 "meaning is the definition, else the translation": D-16 is a stated refinement for offline exercises; read D-09 as applying to /define-based exercises only.
- D-19 (retry, Show answer) vs D-34 (no retry): settled for exams by D-41; D-19 holds only for Stage 2.
- D-17 (instant colour on tap) vs D-34 (no feedback): settled for exams by D-43.
- D-12 (numeric score per word, 0 = not found; lists quiz) vs D-31 (no numeric score): D-31 wins for Stage 3; D-12 holds for Stage 1 and 2.
- D-04 ("Step 3 owns saved results") vs D-33 (nothing saved in v1): read D-04 as "later".
- D-22 (speaker after reveal, lists quiz) vs D-34 (no speaker in exams): D-34 wins for the Quiz.
- D-20 (dialogue lines as sentences) vs D-38 (translation uses a Worker sentence): D-38 already narrows it.
