## Glossary

- option — one of the four answers of a choice question, shown as a button; exactly one is right, the three wrong options come from other words of the group, then the session. NOT a setting (nothing here is configurable).
- question kind — which way a choice question asks: word → translation (kind A) or meaning → word (kind B). NOT a stage (both kinds are Stage 1 here).
- usable word — a word to learn of the selected group for which both question kinds can be built with four different options and only one right answer. NOT a word to learn (a word to learn without a translation is not usable here).
